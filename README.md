# Scramble - Symfony API Documentation Generator

Automatic OpenAPI 3.1.0 documentation generator for Symfony applications.

## Features

- 🚀 **Automatic Documentation**: Generate OpenAPI specs from your Symfony routes and controllers
- 🎯 **Zero Configuration**: Works out of the box with sensible defaults
- 📝 **Type Inference**: Automatically infers request/response types from your code
- 🔍 **PHPDoc Support**: Enriches documentation with PHPDoc comments
- 🎨 **Symfony Standards**: Follows Symfony coding standards and best practices
- ⚡ **Fast**: Efficient parsing and caching mechanisms

## Installation

```bash
composer require dedoc/scramble
```
